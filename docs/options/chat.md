# Chat Messenger / WhatsApp (`chat`)
**Vendu :** « Tes visiteurs te contactent en un clic via Messenger ou WhatsApp. »

1. Préférer un **lien direct** (bouton vers `https://wa.me/<numéro>` ou `https://m.me/<page>`) : aucun script tiers,
   aucun cookie. Numéro / page fournis par le client.
2. Un widget de chat intégré (script Meta) n'est à utiliser que derrière tarteaucitron.
3. Renseigner `prestataires.reseauxSociaux` (ex. « WhatsApp / Meta Platforms Ireland Limited »).
4. Bouton visible sur mobile, accessible (libellé explicite), ne masque pas le contenu.
