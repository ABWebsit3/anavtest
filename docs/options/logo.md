# Création de logo (`logo`)
**Vendu :** « Un logo tout beau tout neuf ! »

1. Recueillir : nom exact, activité, valeurs, couleurs souhaitées/interdites, exemples aimés/détestés.
2. Proposer des pistes, intégrer les retours, livrer les fichiers : SVG, PNG (fond transparent, plusieurs tailles),
   version monochrome, favicon.
3. Mettre à jour `site.couleurs` de la fiche, le favicon (`public/favicon.ico`) et l'image de partage.
4. Vérifier que le logo ne reprend pas une marque existante (recherche INPI/EUIPO) ; le signaler au client.
