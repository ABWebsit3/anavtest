# Newsletter / Emailing (`news`)
**Vendu :** « Un envoi par mois pour tenir tes clients au courant de tes promos. »

1. Outil d'emailing **au nom du client** ; renseigner `prestataires.newsletter` dans la fiche.
2. Formulaire d'inscription : consentement explicite (case non pré-cochée), lien vers la confidentialité,
   double opt-in recommandé ; lien de désinscription dans chaque envoi.
3. Ne jamais importer une liste de contacts sans base légale (prospection B2C = consentement préalable).
4. Prévoir le planning mensuel (1 envoi/mois) avec le client.
